# Spike R1 — TypeScript 7 toolchain compatibility

- **Date:** 2026-11-10
- **Story:** US-002 (M0b)
- **Result:** PASS. TypeScript 7 is used for every compile and type-check. The TypeScript 6 API is kept only for tools that still need the JS compiler API.

## Versions under test
| Tool | Version |
|---|---|
| typescript (TS 7, native) | 7.0.2 |
| @typescript/typescript6 (TS 6 API + `tsc6`) | 6.0.2 (reports TS 6.0.3 internally) |
| next | 16.4.6 |
| typescript-eslint | 8.72.2 (peer `typescript >=4.8.4 <6.1.0`) |
| drizzle-kit | 0.31.11 |
| eslint | 10.14.0 |

## Findings
1. **TS 7 has no classic JS API.**
   - `typescript@7.0.2` exports only `./lib/version.cjs` and `./unstable/*`.
   - typescript-eslint therefore cannot run on it: its peer range is `<6.1.0`.
2. **`@typescript/typescript6` gives typescript-eslint the API it needs.**
   - The package provides the TS 6 API plus a `tsc6` bin, so it does not collide with TS 7's `tsc`.
   - Root alias: `typescript` → `npm:@typescript/typescript6@6.0.2`.
   - Probe: a floating promise in `apps/public/src/lint-probe.ts` triggered `@typescript-eslint/no-floating-promises` → **type-aware lint works**.
3. **Next.js 16.4.6 type-checks through the TypeScript CLI by default** (`useTypeScriptCli: true` in `config-shared.js`, implemented in `runTypeScriptCli.js`).
   - Next resolves `typescript/package.json` from the app directory and supports TS 7's extensionless ESM bin.
   - **Root alias only (TS 6 resolved):**
     - `next build` passed;
     - "Finished TypeScript in 12.5s";
     - Next ran `tsc6`.
   - **`typescript@7.0.2` pinned in `apps/public` devDependencies:**
     - `next build` passed;
     - "Finished TypeScript in 631ms" (about 20× faster);
     - Next ran TS 7.
   - **Probe:** `const x: number = "nope"` failed the build with `error TS2322` → **type errors block the build under TS 7**.
4. **drizzle-kit 0.31.11** loads its config through esbuild/tsx and does not need the TS API.
   - `drizzle-kit generate` produced `0000_*.sql` for a sample `products` table → **works**.
   - The spike migration was deleted afterwards; the real schema arrives in US-009.
5. **Workspace typecheck** uses the root `.bin/tsc`, which is TS 7 from the `ts7` alias. `pnpm -s typecheck` passes for `apps/public`, `packages/db` and `packages/i18n`.

## Decision (applied)
- **Root `package.json`:**
  - `"ts7": "npm:typescript@7.0.2"` provides `tsc` (TS 7) for every `typecheck` script.
  - `"typescript": "npm:@typescript/typescript6@6.0.2"` exists **only** to provide the JS API to typescript-eslint and any other API consumer.
- **Rule: every Next.js app declares `"typescript": "7.0.2"` in its own devDependencies**, so that `next build` type-checks with TS 7.
- Packages without Next use the root TS 7 `tsc`. They need no local TypeScript.
- **Revisit when typescript-eslint supports TS 7's API** (peer range ≥ 7): then drop the TS 6 alias and set root `typescript` to 7.x.
