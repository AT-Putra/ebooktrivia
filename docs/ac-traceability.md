# Acceptance-criteria traceability (US-032, plan §8 item 2)

Every one of the **63** acceptance criteria of the spec (`.omc/specs/deep-interview-ebook-trivia-funnel.md`: AC-S1 to S10, D1 to D8, T1 to T8, Q1 to Q15, A1 to A10, P1 to P12) is mapped below to the story that delivered it and to its evidence: a test (file and title), a Playwright spec, a script, a runbook, or the exact staging step that is still to be done ([go-live.md](go-live.md), items `GL-nn`).

**Checked by `infra/verify/src/ac-traceability.test.ts` (root `pnpm test`).** It fails when an AC of the spec is missing from the table, when a cited file does not exist, when a cited test title is not an `it` / `test` / `describe` of that file (a title only in a comment or a string does not count), when a Staging cell names a `GL-nn` that is not in go-live.md, and when a row marked `staging-pending` has no `GL-nn`. Run it after any rename of a test.

**Columns.** *Story*: the PRD story (or stories) that built it. *Evidence*: `;`-separated citations, a `` `path` `` optionally followed by a `"title"` (a substring of the test's title); a path alone is a script, runbook or whole file. A row that starts with `staging-pending` cannot be fully verified before the staging VM, the domain and the real credentials exist: what is built is cited, and the Staging column names the step that closes it. *Staging*: `-staging-pending (the external-page flow and the ZIP serving are tested locally; the on-demand TLS on a real custom domain is staging only); staging-pending (the HMAC rules are tested against the recorded fixtures; a real signed WAHA delivery is staging only); staging-pending (the units, the provisioning and the stack are proven in the stand-in containers; the real VM is staging only); staging-pending (host-check.sh and the sshd, firewall and dnf-automatic config are proven in the stand-in; SELinux, a real firewall and a real dnf-automatic run are staging only); ` (nothing left to do on staging) or the go-live items that confirm the criterion on the real services even though local evidence exists.
